Work

Featured · Smart India Hackathon demo prototype

AI SAR Command Center

A browser dashboard that turns simulated drone data into rescue decisions: where the drone is, who it found, what is dangerous, and which team to send.

Simulated: drone telemetry, GPS, thermal imagery, detections and confidence, routes, team status. Not connected: no drone, sensor, emergency service or rescue team. Real: the software architecture, state management, map maths, priority logic and UI.

Open live demo Source on GitHub

Tip: press Auto Demo in the demo controls for a 60-second walkthrough.

The problem

After a flood, earthquake or landslide, responders have to combine aerial views, locations and risk quickly. The prototype explores how a single screen could support that decision.
